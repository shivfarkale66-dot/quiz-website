# ⚡ CodeQuiz Pro - Programming Quiz Website

## 🚀 Iske Baare Mein
Ek full-featured programming quiz website jo tumhe React, Python, Java aur DSA seekhne mein help karta hai.

## 🎯 Features
- ✅ **150+ Questions** — React, Python, Java, DSA
- ✅ **User Login/Register** — Alag account system
- ✅ **Admin Dashboard** — Users manage karo, questions add karo
- ✅ **30-second Timer** — Har question ke liye
- ✅ **Score System** — Percentage + Grade
- ✅ **Leaderboard** — Top performers dekho
- ✅ **Resume Text** — Score ko resume mein add karo
- ✅ **Quiz History** — Apne saare attempts dekho
- ✅ **Custom Questions** — Admin naye questions add kar sakta hai
- ✅ **Attractive Dark Theme** — Futuristic UI

## 🌐 Vercel Par Deploy Kaise Karo
1. vercel.com par account banao
2. GitHub mein ye folder upload karo
3. Vercel se GitHub connect karo
4. "New Project" click karo aur repo select karo
5. Deploy! — URL mil jayega

## 💡 College Assignment Notes

- LocalStorage use karta hai data save karne ke liye
- Responsive design — mobile aur desktop dono pe chalega
